Design rules, taken from industrial HMI practice (ISA-101): * Neutral by default. Colour is used only for a state that needs attention, and a colour is never the only signal: every state also has a word and a distinct shape. * Select, then act. The machine list is on the left; everything about the selected machine, and every action on it, is on the right. An action is never further than one row away from the state it changes. * Risk decides placement. Routine operation (desired state) comes first, harmless diagnostics next, and disruptive maintenance last, separated, and confirmed by typing the machine's name. * Feedback where the eye already is. A command's outcome appears in the selected machine's activity list, not in a banner at the top of the page. Same constraints as the Overview template: Horizon's Bootstrap 3 classes plus one inline style block, no new static files, every request same origin with Django's CSRF token.
